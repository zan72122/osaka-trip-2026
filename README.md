# 大阪旅行 11/14–16（2026）

2026年11月14日（土）〜16日（月）の大阪家族旅行で、現地の手元確認用に作った静的ページです。

- 全便・全バスなど「前後の便」まで掲載し、遅延時にも組み直せるようにしています
- 各情報に公式の原典リンク付き
- Service Worker（`sw.js`）でキャッシュし、一度開けばオフラインでも閲覧できます
- スマホで日付タブ（14／15／16／SOS）を切り替える単一ページ構成です

## GitHub Pagesでの公開方法

1. このリポジトリの **Settings → Pages** を開く
2. Build and deployment の Source を **Deploy from a branch** にする
3. Branch は **main** ／ フォルダは **/(root)** を選んで Save
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ホーム画面に追加すると、アプリのように全画面で開けます。
